# Character Converter

![Screenshot of use](https://github.com/Bunkai9448/Marmalade_Boy_SGB/blob/main/Text%20Extraction-Insertion/CharConverter/Converter_screenshot.png)

## Requirements

- Python3 with some older compatibility.
- PyQt5

## How to use

1. Download the full folder.
2. If you are using my files, no need to modify anything. Just run the python script through the console.
3. If you want to put your own tables or images: You can either overwrite the existing ones or open the script
4. in a text editor and change lines 586 through 592, accordingly.
5. Source is SPA font, and Target is JPN font. Everything else is self-explanatory.

You have the screenshot above to see how it should look.

## About

Since the Password System is shared, and can be passed from the play in one language to another, I though a character conversor
could save time. Besides this can help to read a non translated string that has been overlooked if needed.

The full code and "design" is done by AI with my leading and fixing.
