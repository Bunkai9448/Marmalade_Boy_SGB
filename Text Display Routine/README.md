# Text Display Routine - Readme

## English

- This is currently in a working progress, hence the lack of more explanatory info.
- The idea of making this public, in this state, is to let more people participate to ease the process.
- Feel free to push improvements to the code comments.
- Once the routine is well enough understood, I plan on make (a copy with) changes so it displays an 8x4 1bpp for a fan translation.
- The code is written for [Armips fork with z80 for gameboy](https://github.com/Prof9/armips/tree/gameboy/Tests/Z80) which you have built executable here ().

**WARNING!**
Most commments in the ASM where done by AI (the vague ones with only CPU Instruction explanations), 
this is done to help me read the code faster. However, Game explicit data and addresses are commented manually 
by me, with use of the debuggers from [BGB](https://bgb.bircd.org/) and [Mesen2](https://github.com/SourMesen/Mesen2) emulators.
